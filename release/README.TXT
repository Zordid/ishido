Spielbeschreibung
-----------------
 Ishido ist ein kleines, fesselndes Logik-Spiel, bei dem sowohl Glück als auch 
 Geschick zum Erreichen des Spielzieles nötig sind.

Systemvorraussetzungen
----------------------
 Ishido läuft auf allen Computern mit Windows 3.1 oder höher. Auch unter
 Windows 95 und Windows NT gibt es keine Probleme.

Inhalt des Archivs

Installation
------------
 Die Installation ist denkbar einfach. Es genügt die vier Dateien in ein
 beliebiges Unterverzeichnis Ihrer Festplatte zu kopieren. 
 Um Ishido im Programm-Manager von Windows 3.1x zu installieren, legen sie 
 mit "Datei|Neu" ein neues Programm-Icon an und geben im Dialog den kompletten 
 Pfad der Datei ISHIDO.EXE an oder suchen sie mittels "Durchsuchen".
 Ishido benötigt keine Dateien im Windows-System-Verzeichnis. 
 Sollte auf Ihrem System bereits eine BWCC.DLL Datei im Verzeichnis WINDOWS\SYSTEM
 vorhanden sein, so können sie die mitgelieferte Datei einfach löschen.
 Ansonsten können Sie diese Datei auch ins WINDOWS\SYSTEM Verzeichnis
 verschieben, damit auch andere Anwendungen diese DLL nutzen können.
